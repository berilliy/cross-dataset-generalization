Methodology and reproducibility limitations

The 2026-11-25 run completed four strict temporal fits (8 operating points), eighteen exploratory unseen-domain fits (36 operating points), 44 conditional confidence interval rows, and 28 paired comparisons. Every saved prediction group was checked locally against saved confusion counts and F1. No new model selection was performed on final target outcomes.

Intervals use UTC hour clusters for temporal tests and canonical feature vector clusters for heterogeneous tests. They condition on fitted models, chosen thresholds, available traffic and one training seed. Hour blocks and feature groups are not guaranteed independent. No claim about independent deployments or population-level future-day variance is supported. Randomization tests assume cluster-level exchangeability; the Holm family includes all 28 primary macro-F1 comparisons. The numerical minimum raw Monte Carlo p-value is 1/1001. Historical Wilson and row-bootstrap intervals in metrics CSV are IID diagnostics; use the separate cluster interval file for the stated sensitivity analysis.

Three-domain features are log duration and TCP UDP ICMP other indicators. CICIoT2023 flow_duration units and segmentation remain unresolved for this Kaggle derivative. Duration denotes TTL and is excluded; directional byte and packet proxies are excluded. Thus all three-domain conclusions are exploratory. Matching low-dimensional core vectors across domains are reported, not treated as proof of duplicate original flows. Multisource training uses more rows than single-source and uses equal source-by-class training weights. Source-independent common hash rules generate unequal calibration sizes and class prevalences. No universal sample-count or source-diversity causal effect is estimated.

UNSW calibration day has no attacks. Source-calibrated 1% FPR is an empirical constraint on benign source calibration traffic, not a target guarantee. Temporal grouping uses sampled native predictor hashes after float32 conversion and keeps duplicate groups only in the earliest partition, changing the target population. All timestamps are interpreted as UTC Unix values; original capture timezone was not independently validated.

The native temporal models retain possible testbed artifacts including ToN ports and UNSW TCP sequence-like and connection-context counters. Their extraction causality and decision-time availability were not rederived from PCAP. No shared extraction implementation was established across exporters. KS/JSD are descriptive associations and do not establish a causal mechanism.

Only 12 available ToN files and the supplied CICIoT split derivative are used. The UNSW mirror contains 2540047 cleaned records versus the official published 2540044; the three-row discrepancy remains unresolved. Existing CICIDS2017/CSE-CIC-IDS2018 artifacts and historical cleaning totals were retained but not fully rescanned in the final validation. The full corpus count is not the ML training sample size.

The clean assembled notebook has been syntax checked and its experiment cells were executed in the live Kaggle session. It has not been rerun from a fresh kernel end to end; this is an outstanding reproducibility check, not a missing metric. The original interactive notebook and outputs are preserved as evidence. Publication still requires consolidating the historical work-log draft into one consistent manuscript, selecting venue formatting, and independent methodological review.
